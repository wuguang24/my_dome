# 阿里云物模型创建与对接说明（本项目）

## 1. 目标
让 STM32F103 + ESP8266 通过 MQTT 接入阿里云 IoT 平台，实现：
- 属性上报：温湿度/光照/土壤湿度 + 执行器状态 + 模式/报警/阈值
- 属性下发控制：云端修改阈值、开关报警、切换自动/手动、手动模式下控制风扇/水泵/补光灯

## 2. 阿里云 IoT 平台创建步骤（产品与设备）

### 2.1 创建产品
- 物联网平台 → 设备管理 → 产品 → 新建产品
- 联网方式：Wi-Fi
- 数据格式：JSON（推荐）
- 创建后记录 `ProductKey`

### 2.2 添加设备
- 产品下新增设备
- 记录三元组：
  - `ProductKey`
  - `DeviceName`
  - `DeviceSecret`

### 2.3 工程侧 MQTT 参数配置
文件：`my_lib/aliyun_conf.h`
- WiFi：`ALIYUN_WIFI_SSID` / `ALIYUN_WIFI_PASS`
- MQTT Host：`ALIYUN_MQTT_HOST`（形如 `xxx.iot-as-mqtt.cn-shanghai.aliyuncs.com`）
- MQTT Port：1883（本工程 TCP 明文 1883）
- MQTT 身份字段：
  - `ALIYUN_MQTT_USER`
  - `ALIYUN_MQTT_PASS`
  - `ALIYUN_MQTT_CLIENTID`

> 注意：你必须把平台生成/计算出来的 username/password/clientId 填进去，否则不会连到你自己的产品设备。

## 3. Topic 约定（与当前工程一致）

### 3.1 订阅（云端下发属性设置）
- `/sys/${ProductKey}/${DeviceName}/thing/service/property/set`

### 3.2 发布（设备上报属性）
- `/sys/${ProductKey}/${DeviceName}/thing/event/property/post`

## 4. 物模型（属性定义建议：与当前工程字段一致）

> 以下建议按当前工程实现创建；关键是“标识符”要与上报/下发字段一致。

### 4.1 传感器类属性（只读）
- `temp` 温度（int，工程上报为整数）
- `humi` 湿度（int，工程上报为整数）
- `light` 光照lx（int，工程上报为整数）
- `soil` 土壤湿度%（float，工程上报为 1 位小数）

### 4.2 执行器状态（可读写，但建议云端控制只在手动模式生效）
- `fan` 风扇开关（bool 或 int0/1）
- `pump` 水泵开关（bool 或 int0/1）
- `lamp` 补光灯开关（bool 或 int0/1）

### 4.3 模式/报警（可读写）
- `auto_mode` 自动/手动（bool 或 int0/1）
- `alarm_enable` 报警总开关（bool 或 int0/1）
- `alarm_active` 当前是否报警中（bool 或 int0/1）
- `alarm_type` 报警类型（int）
  - 0 无
  - 1 高温
  - 2 低温
  - 3 光照不足
  - 4 土壤过干
  - 5 组合报警

### 4.4 阈值（可读写）
| 属性名 | 数据类型 | 说明 |
| --- | --- | --- |
| `target_temp` | float | 目标温度，精度 0.1 |
| `target_humi` | float | 目标湿度，精度 0.1 |
| `target_light` | float | 目标光照，精度 0.1 |
| `target_soil` | float | 目标土壤湿度，精度 0.1 |
| `alarm_temp_high` | float | 高温报警阈值，精度 0.1 |
| `alarm_temp_low` | float | 低温报警阈值，精度 0.1 |
| `alarm_light_low` | float | 光照不足报警阈值，精度 0.1 |
| `alarm_soil_low` | float | 土壤过干报警阈值，精度 0.1 |

> 说明：当前工程对以上阈值字段使用 `atof()` 解析下发，并以 `%.1f` 进行上报。

## 5. JSON Payload 示例

### 5.1 设备上报（property/post）
Topic：`/sys/.../thing/event/property/post`

```json
{
  "method": "thing/event/property/post",
  "id": "203302322",
  "params": {
    "temp": 26,
    "humi": 55,
    "light": 320,
    "soil": 48.2,
    "fan": 0,
    "pump": 0,
    "lamp": 1,
    "auto_mode": 1,
    "alarm_enable": 1,
    "alarm_active": 0,
    "alarm_type": 0,
    "target_temp": 28.0,
    "target_humi": 60.0,
    "target_light": 500.0,
    "target_soil": 30.0,
    "alarm_temp_high": 35.0,
    "alarm_temp_low": 10.0,
    "alarm_light_low": 100.0,
    "alarm_soil_low": 15.0
  },
  "version": "1.0.0"
}
```

### 5.2 云端下发（property/set）
Topic：`/sys/.../thing/service/property/set`

- 切换手动模式
```json
{"params":{"auto_mode":0}}
```

- 手动模式下控制执行器
```json
{"params":{"fan":1,"pump":0,"lamp":1}}
```

- 修改阈值
```json
{"params":{"target_temp":30,"alarm_temp_low":8}}
```

## 6. 重要逻辑说明（与工程一致）
- `auto_mode=1`（自动模式）时：云端下发 `fan/pump/lamp` 不直接生效（避免与本地自动控制冲突）
- `auto_mode=0`（手动模式）时：云端下发可直接控制执行器
