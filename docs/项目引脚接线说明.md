# 项目引脚接线说明（按当前代码分析）

## 1. MCU 与供电
- MCU：STM32F103（常见 C8T6）
- 所有模块必须共地 GND
- ESP8266 供电必须稳定（建议独立 3.3V，电流裕量足）

## 2. ESP8266（WiFi模块，USART3）
来源：`my_lib/usart3.c`
- USART3_TX：PB10 → ESP8266 RX
- USART3_RX：PB11 ← ESP8266 TX
- 波特率：115200

## 3. 按键（4个）
来源：`my_lib/key.h`
- KEY1：PA6
- KEY2：PA11
- KEY3：PA15
- KEY4：PA1

> 建议接法：按键一端接 GPIO，一端接 GND；GPIO 配上拉输入（按下为低）。

## 4. 执行器输出

### 4.1 风扇模块
来源：`my_lib/fan.h`
- 风扇控制：PB0

### 4.2 水泵模块
来源：`my_lib/bump.h`
- 水泵控制：PB1

### 4.3 补光灯（大功率 LED 模块）
来源：`my_lib/led_module.h`
- 补光灯控制：PA3

### 4.4 蜂鸣器
来源：`my_lib/Buzz.h`
- 蜂鸣器：PB14

## 5. 指示灯（红/绿 LED）
来源：`my_lib/LED.c`
- 红灯：PC13
- 绿灯：PC14

## 6. 传感器输入

### 6.1 DHT11 温湿度
来源：`my_lib/DHT11.h` / `DHT11.c`
- DHT11 数据线：PA8

### 6.2 土壤湿度（模拟量 AO → ADC1）
来源：`my_lib/Soil.h` / `Soil.c`
- 土壤 AO：PA0
- ADC 通道：ADC_Channel_0

### 6.3 光照 GY-302（BH1750，I2C）
来源：`my_lib/MyI2C.c` + `my_lib/GY302.c`
- SCL：PB6
- SDA：PB7

## 7. OLED 显示屏（I2C）
来源：`my_lib/OLED.c`
- OLED_SCL：PB8
- OLED_SDA：PB9

> 注意：BH1750 与 OLED 在当前工程是两套独立的软件 I2C 引脚。
