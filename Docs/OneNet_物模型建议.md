# OneNet 物模型建议（<=10个）

## 目标
面向“STM32F103C8T6 + DHT11/GY-302/JW01 + 执行器(风扇/补光灯/加湿器) + OLED + 按键阈值设置”的大棚环境监测系统，建立不超过 10 个物模型属性，支持：

- 实时环境因子上报
- 云端下发（阈值/执行器）
- 本地阈值联动（温度高→风扇；湿度低→加湿器；光照弱→灯；CO2高→风扇）

## 推荐物模型（共 10 个）

1. `temp`（float / int）
   - **含义**：温度
   - **单位**：℃
   - **方向**：只读（设备上报）

2. `humi`（float / int）
   - **含义**：湿度
   - **单位**：%RH
   - **方向**：只读（设备上报）

3. `light`（int）
   - **含义**：光照强度
   - **单位**：lx
   - **方向**：只读（设备上报）

4. `co2`（int）
   - **含义**：二氧化碳浓度
   - **单位**：ppm
   - **方向**：只读（设备上报）

5. `fan`（bool/int，0/1）
   - **含义**：风扇开关
   - **方向**：可写（云端下发控制） + 可读（设备回传当前状态）
   - **说明**：对应PB14，低电平启动。云端写1表示“希望开启”。

6. `light_sw`（bool/int，0/1）
   - **含义**：补光灯开关
   - **方向**：可写 + 可读
   - **说明**：对应PB13，高电平开启。

7. `humidifier`（bool/int，0/1）
   - **含义**：加湿器开关
   - **方向**：可写 + 可读
   - **说明**：对应PB12，高电平开启。

8. `temp_high`（int）
   - **含义**：温度上限阈值
   - **方向**：可写 + 可读

9. `humi_low`（int）
   - **含义**：湿度下限阈值
   - **方向**：可写 + 可读

10. `light_low`（int）
   - **含义**：光照下限阈值
   - **方向**：可写 + 可读

> 备注：
> - CO2 上限阈值如果也必须云端可配，建议与 `temp_high/humi_low/light_low` 同级增加 `co2_high`，那将超过10个；可选择：
>   - **方案A（不超10个）**：CO2阈值只本地按键配置（不纳入物模型）；
>   - **方案B（替换）**：把 `light_low` 或某个执行器状态改为不建模，换成 `co2_high`。

## 云端下发建议
- 建议使用 OneNet 物模型属性设置主题：
  - `$sys/{proid}/{device}/thing/property/set`
- 设备侧解析 `params` 节点：
  - `fan/light_sw/humidifier`：直接切换执行器（或作为“手动模式请求”）
  - `temp_high/humi_low/light_low`：更新本地阈值数组（与按键设置共用）

## 数据上报建议
- 建议定时（例如 2s 或 5s）上报一次：`temp/humi/light/co2 + fan/light_sw/humidifier`
- 注意DHT11失败、光照无效、CO2无效时：可以不上报该项或上报上次有效值，并附带本地告警逻辑（本项目当前用蜂鸣器报警）。
