# 大棚环境监测系统-实际引脚接线说明（STM32F103C8T6）

本文档按当前工程实际占用引脚整理（含新增硬件串口日志输出 @115200）。未列出的引脚默认不接/不占用。

---

## 1. 供电与公共线

- 3.3V
  - 给：STM32、ESP8266（必须 3.3V 且电流足够）、GY-302、OLED、DHT11（若模块支持 3.3V）、JW01（按模块要求）
- GND
  - 所有模块必须共地

---

## 2. 串口通信

### 2.1 CO2 传感器 JW01（USART1，9600）

- PA9  (USART1_TX) -> JW01_RX
- PA10 (USART1_RX) <- JW01_TX
- GND 共地
- 波特率：9600

说明：USART1 专门留给 CO2 模块，避免与日志/其他外设冲突。

### 2.2 ESP8266 WiFi（USART2，115200）

- PA2 (USART2_TX) -> ESP8266_RX
- PA3 (USART2_RX) <- ESP8266_TX
- PA1 (GPIO 输出) -> ESP8266_RST
- 3.3V / GND
- 波特率：115200

### 2.3 调试日志串口（USART3，PB10/PB11，115200）

- PB10 (USART3_TX) -> USB-TTL_RX
- GND -> USB-TTL_GND
- （可选）PB11 (USART3_RX) <- USB-TTL_TX（一般无需连接）
- 串口参数：115200, 8N1

说明：STM32F103C8T6 常见 48 脚封装不引出 PC10/PC11，因此无法使用 USART3 的 PC10/PC11 重映射。当前工程采用 USART3 默认引脚 PB10/PB11 作为硬件日志输出。

注意：PB10 在原按键定义中为 KEY_UP，因此启用 USART3 后 KEY_UP 将失效或需要改线。

---

## 3. 执行器输出（风扇/灯/加湿）

### 3.1 风扇（低电平有效）

- PB14 -> 风扇驱动输入（IN）
- 低电平有效：PB14 输出 0 为开，输出 1 为关

### 3.2 灯（高电平有效）

- PB13 -> 灯驱动输入（IN）
- 高电平有效：PB13 输出 1 为开

### 3.3 加湿器（高电平有效）

- PB12 -> 加湿器驱动输入（IN）
- 高电平有效：PB12 输出 1 为开

---

## 4. 传感器

### 4.1 DHT11 温湿度

- PA8 -> DHT11_DATA
- 供电：3.3V/GND

### 4.2 光照 GY-302（BH1750，软件 I2C）

- PB6 -> SCL
- PB7 -> SDA
- 供电：3.3V/GND

### 4.3 OLED（软件 I2C）

- PB8 -> SCL
- PB9 -> SDA
- 供电：3.3V/GND

---

## 5. 人机交互

### 5.1 按键（4 路）

- PB0  -> Key
- PB1  -> Key
- PB15 -> Key (Up)
- PB11 -> Key

注意：PB10 已被 USART3_TX 用作日志输出，因此原 PB10 上的按键需要改线到 PB15（Up）。

### 5.2 蜂鸣器

- PA12 -> 蜂鸣器控制

### 5.3 指示灯

- PA6 -> LED
- PA7 -> LED

---

## 6. 最常接错的三组线（快速核对）

- CO2(JW01)：PA9/PA10（9600）
- WiFi(ESP8266)：PA2/PA3 + PA1(RST)（115200）
- 日志串口(USB-TTL)：PB10(TX) + GND（115200）
