# 02 项目文件说明

## 1. 顶层文件

- **`empty.c`**
  - 主入口 `main()`
  - 系统初始化 `SYSCFG_DL_init()`、NVIC 中断使能
  - 初始化 MPU6050（I2C + DMP）、OLED、舵机、蓝牙 DMA
  - 主循环：超声波周期测距（100ms）、蓝牙缓冲处理、OLED 刷新、电压采样
  - 超声波近距检测（仅 BT 模式），更新 `BT_Obstacle_Near`
  - 模式切换处理（自动解除停车、舵机回中）

- **`empty.syscfg`**
  - SysConfig 配置源文件（GPIO/UART/ADC/PWM/SysTick/I2C 等）

- **`ti_msp_dl_config.c/.h`**
  - SysConfig 生成文件（不要手改）

- **`keil/empty_LP_MSPM0G3507_nortos_keil.uvprojx`**
  - Keil 工程文件
  - Before Build 调用 `tools/keil/syscfg.bat`

## 2. Hardware/ 目录（硬件驱动层）

- **`board.c/.h`**
  - 延时 `delay_ms/delay_us`
  - 时基 `tick_ms`、`SysTick_Handler()`
  - 舵机偏移补偿宏 `SERVO_MOUNT_OFFSET`（当前 +25）

- **`bsp_iic.c/.h`**
  - MPU6050 硬件 I2C 适配层（I2C0）

- **`MPU6050.c/.h`**
  - MPU6050 驱动与 DMP 支持
  - 全局姿态：`mpu6050.pitch/roll/yaw`

- **`inv_mpu.c/.h`、`inv_mpu_dmp_motion_driver.c/.h`**
  - InvenSense DMP 库

- **`hcsr04.c/.h`**
  - HC-SR04 阻塞式测距
  - `HCSR04_ReadDistanceCm()` 返回距离（cm），失败返回 -1
  - 异步接口空实现（保留占位，避免链接错误）
  - `servo_angle_offset()` 函数（带安装偏移补偿）

- **`encoder.c/.h`**
  - 编码器 GPIO 中断（Group1）
  - 已合并 MPU6050 INT 中断处理（同组 GPIOA）
  - 已合并 HC-SR04 Echo 中断（保留，但当前使用阻塞式测距）
  - 编码器 A/B 相：E1A=PA25, E1B=PA26, E2A=PB20, E2B=PB24

- **`motor.c/.h`**
  - PWM 输出与电机方向控制

- **`oled.c/.h`、`oledfont.h`**
  - OLED 显示驱动（软件 I2C）

- **`led.c/.h`**
  - 板载 LED 控制（PB9）

- **`key.c/.h`**
  - 按键扫描：单击/双击/三击事件

- **`adc.c/.h`**
  - 电池电压采样

- **`IR_Module.c/.h`**
  - 红外巡线逻辑
  - 纯离散状态机，参考官方例程
  - `IR_USE_ODOM` 宏设为 0（不使用惯性导航）
  - switch 后接 LPF 平滑

## 3. Control/ 目录（控制算法层）

- **`control.c/.h`**
  - 200Hz 控制环中断 `TIMER_0_INST_IRQHandler()`
  - 编码器速度计算、增量 PI 速度控制
  - 蓝牙命令解析 `Get_RC()`
  - 蓝牙近距保护拦截（`BT_Obstacle_Near` 触发时禁止前进）
  - 蓝牙直线航向保持（`Odom_Enable=1` 时生效）
  - 里程计更新 `odom_update_200hz()`
  - 按键处理 `Key()`（单击/双击/三击）

- **`show.c/.h`**
  - OLED 页面绘制（模式、红外状态、速度、编码器、电压）
  - APP 串口输出（A/B/C 帧）
  - DataScope 输出

- **`uart_callback.c/.h`**
  - 蓝牙数据 DMA 接收与解析
  - `BTBufferHandler()` 非阻塞处理
  - `bt_control()` 命令解析（方向/自转/速度/PID 调参）

- **`DataScope_DP.C/.h`**
  - 虚拟示波器协议打包工具

## 4. tools/ 目录

- **`tools/keil/syscfg.bat`**
  - Keil 预编译调用 SysConfig CLI
  - 生成 `ti_msp_dl_config.c/.h`
