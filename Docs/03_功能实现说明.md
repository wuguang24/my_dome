# 03 功能实现说明

## 1. 系统初始化与任务分配

### 1.1 初始化入口
- `empty.c -> main()`
  - `SYSCFG_DL_init()` 外设初始化
  - NVIC 使能：GPIOA Group1（编码器A+MPU6050 INT）、GPIOB Group1（编码器B）、UART0/1、Timer、ADC
  - 初始化：I2C、MPU6050、DMP、OLED、舵机、蓝牙 DMA

### 1.2 周期任务分配

**200Hz 控制环（5ms）**：`Control/control.c -> TIMER_0_INST_IRQHandler()`
- 按键事件 `Key()`
- LED 任务 `LED_Task()`
- 编码器速度计算（基于中断累计计数）
- 里程计更新 `odom_update_200hz()`（可选开关）
- 运行模式处理：
  - Mode=0：蓝牙 `Get_RC()`，含近距保护拦截和航向保持
  - Mode=1：巡线 `IRDM_line_inspection()`
- 舵机摆头跟随（Mode=0/1 均生效）
- 电机 PI 控制输出 PWM

**主循环任务**：`empty.c`
- 蓝牙缓冲处理 `BTBufferHandler()`
- 电压采样 `Get_battery_volt()`
- 超声波周期测距（100ms）更新 `Distance`
- 蓝牙近距检测（仅 Mode=0）更新 `BT_Obstacle_Near`
- OLED/APP 输出

**GPIO 外部中断**：`Hardware/encoder.c`
- 编码器计数更新（A/B 相 quadrature）
- MPU6050 INT 下降沿触发 `Read_DMP()`
- Echo 中断保留（但当前使用阻塞式测距）

---

## 2. MPU6050（DMP 姿态）

- 引脚：I2C0 PA0/PA1，INT PA7
- ISR：合并到 `encoder.c` 的 Group1/GPIOA 中断
- 数据：`mpu6050.pitch/roll/yaw` 在 ISR 更新
- DMP 中断频率约 200Hz

---

## 3. HC-SR04 超声波测距

- 引脚：Trig PA24，Echo PA9（配置下拉电阻）
- 驱动：`Hardware/hcsr04.c -> HCSR04_ReadDistanceCm()`
  - 阻塞式测量，20us Trig 脉宽
  - 使用 `tick_ms + SysTick->VAL` 做高精度计时
  - 返回值：`>0` 有效距离（cm），`-1` 超时失败
- 主循环每 100ms 调用一次
- `Distance` 存储为 **mm*10** 整形

### 3.1 蓝牙近距保护
- 实现位置：`empty.c` 主循环
- 条件：Mode=0 且（Distance < 100 即 < 10cm）
- 盲区保护：测距失败且上次有效距离 < 150（15cm）时也视为近距
- 标志位：`BT_Obstacle_Near`

### 3.2 刹车拦截
- 实现位置：`Control/control.c -> Get_RC()`
- 触发：`BT_Obstacle_Near == 1 && Move_X > 0`
- 行为：强制 `Move_X=0, Move_Z=0`，清空 `Flag_Direction/Flag_Left/Flag_Right`

---

## 4. 红外巡线实现

### 4.1 传感器读取
- 4 个红外传感器直接读取 GPIO，无滤波
- 组合成 `DH_state`（4bit，DH1 在 bit3，DH4 在 bit0）

### 4.2 状态机
- 参考官方例程，仅处理 9 个有效状态
- `case 0`：十字路口，停 5 秒（1000 个周期@200Hz）后直行
- `case 1/8`：直角弯，速度 0.3，转向角速度 2.3 rad/s
- `case 7/14`：大弯，速度 0.7，转向 1.03 rad/s
- `case 11/13`：微调，速度 0.8，转向 ±0.25 rad/s
- `case 9`：直行
- `case 15`：丢线，按 `last_state` 摆头找线

### 4.3 平滑处理
- switch 后一阶低通滤波：`Move_Z_lpf = Move_Z_lpf * 0.5 + Move_Z * 0.5`
- 抑制传感器跳变导致的蛇形

### 4.4 与惯性导航的关系
- `IR_Module.c` 中 `IR_USE_ODOM` 宏设为 0
- **巡线模式不使用惯性导航**
- 纯红外离散状态机，与官方例程一致

---

## 5. 惯性导航（里程计）

### 5.1 差速里程计模型
- `v = (v_l + v_r)/2`
- `w = (v_r - v_l)/Wheelspacing`
- `theta = theta + w*dt`
- `x = x + v*cos(theta)*dt`
- `y = y + v*sin(theta)*dt`

### 5.2 与 MPU6050 yaw 的互补融合
- 编码器积分主导
- MPU6050 yaw 弱校正（`k_yaw = 0.02`）

### 5.3 蓝牙航向保持
- 实现位置：`control.c -> Get_RC()`
- 条件：`Odom_Enable=1`、无主动转向（|Move_Z| < 0.15）、在前进（|Move_X| > 0.05）
- 行为：锁定当前航向，每 5ms 叠加微弱转向修正（±0.15 rad/s 限幅）
- 用户主动打方向时立即解锁

### 5.4 按键控制
- 三击按键切换 `Odom_Enable`
- 开启时清零 `Odom_X/Y/Theta`

---

## 6. 舵机控制

### 6.1 安装偏移补偿
- `board.h`：`SERVO_MOUNT_OFFSET = +25`
- 超声波朝右偏时，正值向左修正
- `servo_angle_offset()`：基础角度 + 偏移量，限制 0~180

### 6.2 摆头跟随
- 实现位置：`control.c` 控制环
- 条件：`Run_Mode == 0 || Run_Mode == 1`
- 公式：`servo_deg = 90 + Move_Z * 40`
- 限制：30°~150°（逻辑），实际 55°~175°（含 +25 偏移）
- 切换模式时自动回中

---

## 7. 蓝牙数据接收

### 7.1 DMA 接收
- UART1 使用 DMA 通道 0 接收
- 缓冲区大小 200 字节
- `BTBufferHandler()` 主循环中轮询处理

### 7.2 命令解析
- `bt_control()` 解析方向/自转/速度/PID 调参命令
- 停车状态下过滤非 UI 命令（防止解锁时突然冲出去）
- 速度调节需快速双击（80ms 内两次相同字节）
- 蓝牙超时 300ms 自动清零方向标志

---

## 8. 输出与验证

### 8.1 串口输出
- `DataScope()`：
  - CH1：航向角（度）
  - CH2：距离（cm）
  - CH3：X 位置（m）
- APP 输出：
  - A 帧：编码器速度、电压、距离
  - B 帧：pitch/roll/yaw*100
  - C 帧：PID 参数

### 8.2 OLED 显示
- 第 1 行：Car_Mode（Diff）+ Run_Mode（APP/IRF）
- 第 2 行：DH1~DH4 传感器状态
- 第 3 行：Move_Z 转向速度
- 第 4~5 行：左右编码器目标/实际速度
- 第 6 行：电压 + Flag_Stop（ON/OFF）
