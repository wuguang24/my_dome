# STM32 语音控制智能香薰灯

基于 **STM32F103C8T6** 的智能香薰灯,支持 **ASR 语音模块串口控制**、PWM 无级调光、香薰加湿多档位控制、水位缺水保护与环境温湿度显示,打造声光香一体的智能家居单品。

## 功能特性

### 🎙️ 语音控制(USART3 串口协议)
- "切换自动/手动模式"
- "打开/关闭灯光"、"调到几档亮度"(50% / 75% / 100%)
- "打开/关闭香薰"、"香薰换挡"、"打开香薰几档"
- 6 字节帧协议(帧头 55 AA + 功能字 + XOR 校验),详见 [语音指令串口协议.md](语音指令串口协议.md)

### 💡 灯光控制(PWM 调光)
- **手动模式**:按键/语音设置亮度档位(50% → 75% → 100% → 0% 循环)
- **自动模式**:根据光敏(LDR)光照值自动调光,阈值以下 100%,阈值~998 线性递减

### 💨 香薰/加湿控制
- 4 档间隔模式:常开 / 每 30s 开 5s / 每 60s 开 5s / 每 120s 开 5s
- **缺水保护**:水位传感器检测缺水时强制关闭香薰 + 蜂鸣器每 2s 提示,恢复后需手动重启

### 🖥️ 人机交互
- OLED 显示温湿度/光照/亮度/模式/香薰状态
- 4 按键操作:模式切换、亮度调节、香薰开关、香薰换挡、阈值设置(Flash 保存)
- DHT11 温湿度采集
- 预留 WiFi 模块(USART2,机智云 Gizwits)与超声波/人体红外接口

## 硬件组成

| 模块 | 引脚 | 说明 |
|------|------|------|
| 光敏 LDR | PA0 | ADC 采集 |
| 加湿器/香薰 | PA1 | 开关输出 |
| 水位检测 | PA4 | 有水=低电平 |
| 蜂鸣器 | PA5 | — |
| DHT11 | PB12 | 单总线 |
| OLED | PB1(SCL)/PB0(SDA) | 软件 I2C |
| KEY1~KEY4 | PB8 / PB7 / PB6 / PB5 | 上拉输入 |
| 语音模块 | PB10(TX)/PB11(RX) | USART3 @9600 |
| WiFi(预留) | PA2(TX)/PA3(RX) | USART2 @9600 |
| 调试串口 | PA9(TX)/PA10(RX) | USART1 @115200 |

## 目录结构

```
├── User/               # 主程序(业务逻辑)
├── Hardware/           # 硬件驱动(DHT11/水位/蜂鸣器/按键/OLED 等)
├── System/             # 系统级代码(delay/sys/usart)
├── Library/            # STM32 标准外设库
├── Start/              # 启动文件
├── Project.uvprojx     # Keil MDK 工程
├── 引脚接线与使用说明.md  # 引脚表 + 功能使用说明
└── 语音指令串口协议.md    # 语音模块串口帧格式与指令映射
```

## 快速开始

1. 使用 **Keil MDK** 打开 `Project.uvprojx`,编译下载至 STM32F103C8T6
2. 按接线表连接外设(所有模块共地)
3. 语音模块按 [语音指令串口协议.md](语音指令串口协议.md) 配置关键词与对应串口指令
4. 上电默认:香薰关闭、手动模式亮度 0
