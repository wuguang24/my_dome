# STM32 大棚环境监测与控制系统

基于 **STM32F103 + ESP8266 + OneNet 云平台** 的大棚环境监测与控制系统,采集**温湿度、光照、CO₂ 浓度**,本地自动控制**风扇/补光灯/加湿器**,并支持云端远程监控与接管。

## 系统架构

```
┌──────────────┐   MQTT    ┌──────────────┐  USART2(AT)  ┌──────────────────┐
│  OneNet 云平台 │ ←───────→ │    ESP8266   │ ←──────────→ │     STM32F103    │
│  (物模型/监控) │  属性上报/  │  (WiFi 网关) │   115200     │ 采集·报警·执行器  │
│              │  远程下发   └──────────────┘              └──────────────────┘
└──────────────┘
```

## 功能特性

### 🌡️ 环境采集(100ms 周期)
- **DHT11** 温湿度
- **BH1750 (GY-302)** 光照强度(lux)
- **JW01** CO₂ 浓度(ppm,USART1 串口协议解析)
- **OLED** 实时显示监测值与 H/L 报警标志

### ⚙️ 执行器自动控制(带滞回)
- 温度/湿度/CO₂ 越限 → 风扇
- 光照不足 → 补光灯
- 湿度低于下限 → 加湿器

### 🚨 阈值报警
- 任意参数超出上下限触发蜂鸣器报警
- 4 按键本地设置各参数阈值(温度/湿度/光照/CO₂ 的上下限)

### ☁️ 云端功能(OneNet MQTT)
- 每 2 秒周期上报全部数据
- **远程接管**:云端下发执行器状态优先于本地自动控制,带接管超时自动回退
- 远程模式切换与阈值下发

## 快速开始

1. **云平台**:注册 [OneNet](https://open.iot.10086.cn/),创建 MQTT 产品与设备,按 `Docs/OneNet_物模型建议.md` 建物模型
2. **配置联网**:在工程中修改 WiFi 与 OneNet 设备鉴权信息
3. **编译烧录**:Keil MDK 打开 `Project.uvprojx`,编译下载至 STM32F103C8T6
4. **查看日志**:USART3(PB10 TX)@115200 输出运行日志

## 引脚速查

| 模块 | 引脚 | 说明 |
|------|------|------|
| JW01 CO₂ | PA9(TX)/PA10(RX) | USART1 @9600 |
| ESP8266 | PA2(TX)/PA3(RX) + PA1(RST) | USART2 @115200 |
| 调试日志 | PB10(TX) | USART3 @115200 |
| DHT11 | PA8 | 单总线 |
| BH1750 | PB6(SCL)/PB7(SDA) | 软件 I2C |
| OLED | PB8(SCL)/PB9(SDA) | 软件 I2C |
| 风扇 | PB14 | 低电平有效 |
| 补光灯 | PB13 | 高电平有效 |
| 加湿器 | PB12 | 高电平有效 |
| 按键 K1~K4 | PB0 / PB1 / PB15 / PB11 | 模式/选择/加/减 |
| 蜂鸣器 | PA12 | — |
